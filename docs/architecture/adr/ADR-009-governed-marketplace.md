# ADR-009: Build a Governed Multi-Publisher Marketplace

- Status: Accepted baseline
- Date: 2026-11-21

## Context
The marketplace includes internal products and independent publishers. Open publishing without trust controls exposes users to malicious artifacts, deceptive permissions, and licensing disputes.

## Decision
Use publisher verification, artifact integrity, permission disclosure, risk-based evaluation, license and entitlement checks, quarantine/takedown, and appeal processes.

## Consequences
- A listing does not grant execution permission.
- Publisher IP remains publisher-owned unless separately assigned.
- Commercial and marketplace legal terms require separate review.
- Foundation defines trust policy; operator runs marketplace workflows.
